Getting started

Foundation ready

The control plane is up: accounts, sessions and the shared resource registry all work. Services plug into that registry — each one stores its objects as rows with its own service type, so this console lists them without any change to the dashboard.

  1. Create an API key to talk to the API from scripts or a CLI.
  2. Add the first service blueprint under app/services/.
  3. Register resources through the registry — they appear here instantly.
